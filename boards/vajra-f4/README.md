# VAJRA F4

- MCU: STM32F405 (1 MB flash)
- Reports itself over MSP (MSP_BOARD_INFO) as: `VAJRAF4` (check the amidFly Firmware Flasher's Board
  card and keep `match` in manifest.json in sync)
- Bluetooth bridge: ESP32-C3 ("SpeedyBee-C3"), flashes the STM32 over BLE
